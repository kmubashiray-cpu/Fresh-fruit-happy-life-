# Fresh-fruit-happy-life-🍎 Yakub Fruits — Fresh Fruit Fresh Life

Welcome to Yakub Fruits, a fruit shop website project for Jamkhandi, Karnataka.

Features

- Fresh fruit catalogue with photos
- Search fruits by name
- Category filters
- Shopping cart and quantity controls
- Discount calculator
- WhatsApp ordering
- Fruit shelf-life guide
- Duplicate barcode scanner demo
- UPI payment link helper
- QR code image preview
- Google Maps and route links
- Shop contact information
- Mobile-friendly design

Shop Details

- Shop Name: Yakub Fruits
- Location: Jamkhandi, Karnataka
- Phone: 9353450122
- Tagline: Fresh Fruit Fresh Life

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open "index.html" in a browser or use Acode's Preview option.
3. Internet access is required for external fruit images.
4. Host the website using GitHub Pages to share it online.

Important Notes

- Product prices and discounts are examples only.
- Confirm current prices and availability with the seller.
- Use only the seller's verified UPI ID and genuine payment QR.
- The barcode scanner is a demo and does not verify product authenticity.
- Confirm the shop's exact address before travelling.

Project Purpose

This project demonstrates a simple online fruit shop with product search, shopping cart, discounts, contact details, and local navigation.

Made for local fruit lovers in Jamkhandi. 🍊
